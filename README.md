# よる時計 (Yoru Clock)

| 項目 | 内容 |
| --- | --- |
| バージョン | v1.0.0 |
| 状態 | ✅ 開発中 |
| 稼働先 | Android 端末（ローカルアプリ） |
| 実装 | Kotlin 2.0.21 + Jetpack Compose (手動ビルド) |

時計・アラーム・タイマー・ストップウォッチ・世界時計を 1 つにまとめたオフライン時計アプリ。ネットワーク通信は行わず、すべてのデータを端末内に保存する。アラームは Android 標準のアラームクロック機能で発火させるため、省電力モードでも時刻どおりに鳴る。

## 機能

| 画面 | 機能 |
| --- | --- |
| 時計 | デジタル時計（秒表示）＋アナログ時計（滑らかな針の動き）、日付表示 |
| 世界時計 | 既定 6 都市（東京・ソウル・ロンドン・ニューヨーク・ロサンゼルス・シドニー）、カタログ 18 都市から追加、長押しで削除確認、日本との時差表示 |
| アラーム | 任意個数のアラーム、曜日繰り返し、ラベル、次回発火日時の表示、スヌーズ（5 分・鳴動画面から） |
| タイマー | 時・分・秒の指定、プリセット（1/3/5/10/15/30/60 分）、進捗バー、一時停止・再開、終了時にアラームと同じ鳴動 |
| ストップウォッチ | ラップ計測（新しい順に表示）、1 時間以上は H:MM:SS 形式で表示 |

## アラームの仕組み

| 項目 | 内容 |
| --- | --- |
| 発火 | `AlarmManager.setAlarmClock` を使用（正確なアラームの許可は不要） |
| 鳴動 | ロック画面の上に全画面で表示、既定のアラーム音をループ再生＋バイブレーション、10 分で自動停止 |
| 通知 | 重要度 HIGH の通知（全画面インテント付き）。通知権限が無くても鳴動画面は直接開く |
| 再登録 | 端末再起動・時刻変更・タイムゾーン変更・アプリ更新時に、保存済みアラームをすべて再登録 |

## 設定と保存先

| 保存先 | キー | 内容 |
| --- | --- | --- |
| SharedPreferences `alarms` | `alarms_json` | アラーム一覧（JSON 配列） |
| SharedPreferences `world` | `cities_json` | 世界時計の都市一覧（タイムゾーン ID の配列） |
| SharedPreferences `timer` | `end_millis` / `total_millis` / `remaining_millis` / `running` | タイマーの終了時刻・合計・残り・動作状態 |

## 権限

| 権限 | 用途 |
| --- | --- |
| `POST_NOTIFICATIONS` | アラーム・タイマー終了の通知表示（Android 13 以降、起動時に許可を求める） |
| `USE_FULL_SCREEN_INTENT` | ロック画面上に鳴動画面を表示 |
| `RECEIVE_BOOT_COMPLETED` | 再起動後のアラーム再登録 |
| `VIBRATE` | 鳴動時のバイブレーション |

インターネット権限は付けていない（完全オフライン）。

## ビルド

```bash
./build.sh              # 単体テスト → APK ビルド → 署名 → dist/yoru-clock.apk
./build.sh --skip-tests # テストを省略
```

Windows では `build.bat`（Git Bash / WSL 経由で `build.sh` を実行する）。

- ツールチェーン: JDK 21、Kotlin コンパイラ 2.0.21、Android SDK（platform android-34 / build-tools 34.0.0）
- 依存ライブラリ（Compose 1.7.6 / Material3 1.3.1 / activity-compose 1.9.3 等）は `python3 tools/resolve.py` で `libs/` に取得する
- 署名: 既定は同梱の `debug.keystore`。自分の鍵で署名する場合は環境変数で指定する（値はファイルに書かない）

| 環境変数 | 内容 |
| --- | --- |
| `YORU_CLOCK_KEYSTORE` | 鍵ストアのパス |
| `YORU_CLOCK_KEYSTORE_PASS` | 鍵ストアのパスワード |
| `YORU_CLOCK_KEY_ALIAS` | 鍵のエイリアス（既定 `androiddebugkey`） |
| `YORU_CLOCK_KEY_PASS` | 鍵のパスワード（既定はストアと同じ） |

## 既知の制限

- 実機での動作確認は未実施（鳴動・ロック画面表示・電池最適化の影響は端末依存）
- 既定の署名はデバッグ鍵のため、配布時は `YORU_CLOCK_*` で自分の鍵を指定する
- アラーム音の音量は端末のアラーム音量に従う（アプリ内での音量調整なし）
- 世界時計の都市は固定カタログ 18 都市のみ（任意のタイムゾーン追加は不可）
- ストップウォッチの状態は保存しない（画面を離れるとリセットされる）
- スヌーズは鳴動画面からのみ可能（通知からは不可）
- 通知権限を許可していない場合、鳴動画面は開くが通知は表示されない
- タイマーは壁時計（終了時刻）基準のため、端末の時刻を変更すると終了時刻もずれる
